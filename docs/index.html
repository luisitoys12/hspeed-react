Cómo Ejecutar en PC Local (Paso a Paso)

1

Clonar el repositorio

Descarga el código fuente oficial desde GitHub:

git clone https://github.com/luisitoys12/hspeed-react.git && cd hspeed-react
2

Instalar las dependencias

Instala los paquetes de Node.js necesarios (versión 18 o 20 LTS):

npm install
3

Iniciar todo con 1 Clic

Inicia automáticamente el servidor de radio en puerto 8005 y la web en puerto 5000:

  • En Windows: Haz doble clic en el archivo start-all.bat en la raíz del proyecto.
  • En Linux / Mac: Ejecuta ./start-all.sh o npm run start:all en tu terminal.
4

Abrir en el Navegador

Disfruta de la plataforma y sintoniza la radio:

http://localhost:5000

Suite de Verificación Automatizada

Antes de entregar o migrar el código a producción, puedes correr la suite de pruebas End-to-End con Playwright:

npm run verify:ui

✅ Valida portada sin pantalla negra · ✅ Valida botón verde de Play con audio activo (readyState 4) · ✅ Comprueba 6 rutas principales sin errores.
