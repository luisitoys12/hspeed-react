🐳 Despliegue Contenerizado con Docker

Instrucciones completas para levantar HabboSpeed en contenedores Docker de producción con PostgreSQL y healthcheck automático.

Inicio en un solo comando

Desde la raíz del proyecto o desde la carpeta docker/:

cd docker && docker compose up --build -d

Esto levanta automáticamente el contenedor de base de datos PostgreSQL 16 (puerto 5432) y la aplicación web compilada multi-stage en el puerto 5000.

Variables de Entorno

Variable Descripción Valor por Defecto
NODE_ENV Entorno de ejecución production
PORT Puerto interno de la app 5000
DATABASE_URL Cadena de conexión PostgreSQL postgres://hspeed:hspeed@db:5432/hspeed
PGSSL Forzar SSL en la base de datos false (local) / true (Supabase)
JWT_SECRET Firma de tokens de sesión habbospeed_secret_key_2026
