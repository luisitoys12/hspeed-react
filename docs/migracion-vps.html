🚀 Guía de Migración y Despliegue en Servidor VPS

Manual paso a paso para migrar HabboSpeed a cualquier servidor VPS en la nube (Ubuntu 22.04/24.04 o Debian 12) con Nginx, PM2 y SSL.

1

Instalar Node.js 20 LTS, Nginx y PM2

Ejecuta estos comandos en la terminal SSH de tu VPS:

curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash - && sudo apt install -y nodejs nginx git && sudo npm install -g pm2
2

Clonar el Repositorio y Compilar el Proyecto

Descarga la aplicación en /var/www/ e instala dependencias:

cd /var/www && git clone https://github.com/luisitoys12/hspeed-react.git && cd hspeed-react && npm install && npm run build
3

Iniciar Procesos Persistentes con PM2

Inicia la web en puerto 5000 y la radio en puerto 8005 con auto-arranque en reinicios:

pm2 start "node dist/index.cjs" --name "hspeed-web" && pm2 start "node script/azuracast-server.cjs" --name "hspeed-radio" && pm2 save && pm2 startup
4

Configuración de Nginx Reverse Proxy

Guarda esta configuración en /etc/nginx/sites-available/habbospeed.conf:

server {
    listen 80;
    server_name tudominio.com www.tudominio.com;

    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }

    location /listen/ {
        proxy_pass http://127.0.0.1:8005;
        proxy_set_header Host $host;
    }
}
sudo ln -s /etc/nginx/sites-available/habbospeed.conf /etc/nginx/sites-enabled/ && sudo nginx -t && sudo systemctl reload nginx
5

Generar Certificado SSL Gratuito (HTTPS)

Protege tu dominio con cifrado seguro Let's Encrypt:

sudo apt install -y certbot python3-certbot-nginx && sudo certbot --nginx -d tudominio.com -d www.tudominio.com
